## How to run the mobile app
1. Install the Flutter SDK and Android Studio, then start an Android emulator.
2. `git clone https://github.com/pmganga/linear_regression_model.git`
3. `cd linear_regression_model/summative/FlutterApp`
4. `flutter pub get`
5. `flutter run`
6. Enter the values and tap **Predict**. The first request may take up to a minute while the API wakes up.
